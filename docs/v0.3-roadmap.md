# Trace v0.3 - La app que piensa contigo

Fecha: 2026-06-06
Base: v0.2.3 estable, CI verde, desktop y self-host funcionando.

## Vision

Trace v0.3 es la version donde la app deja de ser solo un lugar donde guardas notas y se convierte en un sistema que trabaja para ti.

Principios:

- Cero friccion de captura: la idea se anota antes de que la pierdas.
- Organizacion automatica: Trace conecta, tu decides.
- La app se adapta a ti: sin tocar codigo.

## Feature 1 - Conexiones inteligentes con control total

Trace sugerira conexiones usando similitud local sobre SQLite FTS5 y TF-IDF. No usa IA externa, API keys ni servicios remotos.

Comportamiento:

- El panel derecho muestra "Posibles conexiones" al abrir una nota.
- Cada sugerencia muestra titulo, fragmento relevante y barra visual de similitud.
- Aceptar crea una relacion en `note_relations`.
- Rechazar guarda el par en `ignored_suggestions`.
- Ignorar no persiste nada.
- Los `[[wiki-links]]` siguen funcionando igual.

Implementacion:

- `trace-core`: `suggest_connections(note_id, vault_db) -> Vec<SuggestedConnection>`.
- Nueva tabla: `ignored_suggestions(source_id, target_id, ignored_at)`.
- Frontend: `RightPanel.tsx`, `SuggestionCard`, `useConnectionSuggestions(noteId)`.

## Feature 2 - Captura instantanea global

Atajo global para capturar una idea sin abrir todo Trace.

Comportamiento:

- `Ctrl+Space` abre una ventana Tauri secundaria de 480x120 px.
- `Enter` guarda la captura.
- `Escape` cierra sin guardar.
- La primera linea se usa como titulo provisional.
- La nota cae en una Bandeja de entrada.

Bandeja:

- Seccion especial en el sidebar con badge de count.
- Las notas de bandeja muestran sugerencias de destino.
- No contaminan el grafo principal hasta procesarse.

Implementacion:

- `src-tauri`: ventana `quick-capture`.
- Plugin: `tauri-plugin-global-shortcut`.
- Comando: `create_inbox_note(content) -> note_id`.
- `trace-core`: campo `nodes.inbox BOOLEAN DEFAULT 0`.
- Frontend: `QuickCaptureWindow`, `InboxSection`, `InboxNoteCard`.

## Feature 3 - Editor adaptable sin codigo

Dos capas:

- Escritura libre con inferencia de formato.
- Panel visual de Apariencia para tipografia, editor, colores, grafo y layout.

Reglas iniciales de inferencia:

- Linea corta sola seguida de linea en blanco: H2.
- `-`, `*` o `1.`: lista.
- Bloques indentados o entre backticks: codigo.
- `/` sigue funcionando como comando explicito.

Configuracion esperada en `trace.config.json`:

```json
{
  "layout": {
    "sidebar_position": "left",
    "right_panel": "visible",
    "visible_elements": {
      "breadcrumb": true,
      "metabar": true,
      "word_count": true,
      "modified_at": true,
      "titlebar": true
    }
  }
}
```

## Feature 4 - Vista "En que estaba"

La pantalla de inicio reemplaza el workspace generico con contexto de regreso.

Secciones:

- Ultima sesion.
- Esta semana.
- Sin terminar.
- De hace mas de 30 dias.

Deteccion de notas sin terminar:

- Checkboxes sin marcar con `updated_at > 48h`.
- Ultimo bloque de texto sin punto final.
- Notas recientes con pocas ediciones.

Implementacion:

- SQL sobre datos existentes.
- Persistencia de posicion de cursor en el slice del editor.

## Feature 5 - Grafo accionable y personalizable

El grafo debe explicar y permitir actuar.

Tipos visuales:

- Huerfanos: color configurable, rojo suave por defecto.
- Puentes: color accent y mayor tamano.
- Recientes: borde con glow.
- Clusters: color por grupo.

Acciones:

- Click en nodo: abrir nota.
- Click en nodo huerfano: abrir sugerencias de conexion.
- Click en cluster: lista de notas del tema.
- Hover: preview.
- Doble click en area vacia: fit all.

Implementacion:

- `trace-core/graph.rs`: detectar clusters, puentes y huerfanos.
- Frontend: `GraphView.tsx`, `ClusterPanel.tsx`.

## Feature 6 - Ejecucion de codigo en bloques

Boton Run en bloques de codigo para ejecutar localmente y mostrar output temporal.

Comportamiento:

- Detecta runtimes instalados.
- Timeout por defecto: 30 segundos.
- Output maximo: 10.000 caracteres.
- Advertencia de seguridad en primera ejecucion.
- Boton de detener si tarda mas de 3 segundos.
- El output no se guarda en la nota.

Implementacion:

- `src-tauri/src/commands/code_runner.rs`.
- `detect_runtimes()`.
- `run_code_block(lang, code, timeout) -> CodeOutput`.
- Frontend: `CodeRunnerBlock`, `RunButton`, `OutputPanel`, `useCodeRunner`.

## Orden de implementacion

1. Semana 1: captura instantanea global y Bandeja de entrada.
2. Semana 2: vista "En que estaba".
3. Semana 3: panel de personalizacion visual.
4. Semanas 4-5: conexiones inteligentes con TF-IDF.
5. Semana 6: grafo accionable.
6. Semana 7: ejecucion de codigo en bloques.

## No entra en v0.3

- IA generativa o LLMs externos.
- Sync automatico con resolucion de conflictos.
- Multiusuario.
- Templates.
- Mas vistas de base de datos.

## Criterio de version completa

Trace v0.3 se considera completo cuando un usuario puede:

- Capturar una idea con `Ctrl+Space` sin abrir la app completa.
- Volver a Trace y ver en que estaba.
- Recibir sugerencias de conexiones locales y aceptar o rechazar.
- Usar el grafo para descubrir clusters y abrir notas.
- Ejecutar un bloque de codigo local desde una nota.
- Personalizar layout y apariencia desde Settings, sin editar JSON.
